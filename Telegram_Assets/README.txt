CARA PAKAI
----------
1. Cari produk berdasar folder.
2. Untuk detail bahan/harga, buka 00_Deskripsi_Produk/ dan cari postID terdekat.
3. Link asli tiap foto ada di _metadata.csv kolom link.
4. Penamaan file: yarka_{postID}.jpg = ID pesan asli di Telegram.
5. Untuk aset website hasil kurasi, buka 08_Update_Sep-Okt_2026/_curated.csv:
   kolom target = file di assets/img, source_post_id = foto asli di Telegram.
